Known issues

  • Turned-up boost on modified carsOutlet report

    RAC's used Evo VII guide says to look for aftermarket fuel cuts or cable ties around the turbo hoses, signs the boost has been raised. It calls the engine itself untemperamental.

  • AYC needs the dealer toolOutlet report

    Most Evo VIIs have Active Yaw Control, and RAC says servicing it needs Mitsubishi's MUT-II diagnostic tool, so a specialist is the safer bet.

  • Grey-import checksOutlet report

    RAC says Japanese-market cars need the 112 mph speed limiter removed, an mph speedometer and odometer, a rear fog light and proper underseal. It also says any trim can be dressed up as another, so check RS and GSR identity.
