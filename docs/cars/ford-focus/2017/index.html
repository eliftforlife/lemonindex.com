When problems show up

Half of the Ford Focus complaints that listed a mileage came before 55,000 miles. Most came between 25,800 miles and 80,800 miles.

The top problem area, transmission & drivetrain, usually showed up between 20,000 miles and 80,000 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
