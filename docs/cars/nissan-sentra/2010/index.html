When problems show up

Half of the Nissan Sentra complaints that listed a mileage came before 69,300 miles. Most came between 17,900 miles and 100,000 miles.

The top problem area, electrical, usually showed up between 37,200 miles and 117,800 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
