When problems show up

Half of the Chevrolet Malibu complaints that listed a mileage came before 82,000 miles. Most came between 53,000 miles and 113,400 miles.

The top problem area, steering, usually showed up between 75,000 miles and 135,000 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
