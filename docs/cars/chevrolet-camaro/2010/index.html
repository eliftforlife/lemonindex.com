When problems show up

Half of the Chevrolet Camaro complaints that listed a mileage came before 48,000 miles. Most came between 20,000 miles and 74,000 miles.

The top problem area, airbags, usually showed up between 34,800 miles and 65,000 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
