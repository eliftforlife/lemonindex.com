When problems show up

Half of the Chevrolet Silverado complaints that listed a mileage came before 60,000 miles. Most came between 31,500 miles and 100,000 miles.

The top problem area, airbags, usually showed up between 52,400 miles and 122,000 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
