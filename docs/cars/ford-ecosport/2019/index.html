When problems show up

Half of the Ford EcoSport complaints that listed a mileage came before 67,000 miles. Most came between 50,000 miles and 80,000 miles.

The top problem area, engine, usually showed up between 54,000 miles and 81,000 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
