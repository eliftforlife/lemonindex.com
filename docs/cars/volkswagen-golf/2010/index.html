When problems show up

Half of the Volkswagen Golf complaints that listed a mileage came before 40,000 miles. Most came between 10,000 miles and 73,000 miles.

The top problem area, engine, usually showed up between 48,100 miles and 90,800 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
