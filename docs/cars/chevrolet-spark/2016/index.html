When problems show up

Half of the Chevrolet Spark complaints that listed a mileage came before 11,000 miles. Most came between 2,700 miles and 44,800 miles.

The top problem area, brakes, usually showed up between 2,600 miles and 34,200 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
