When problems show up

Half of the Kia Telluride complaints that listed a mileage came before 6,000 miles. Most came between 1,700 miles and 23,600 miles.

The top problem area, lights, usually showed up between 800 miles and 64,500 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
