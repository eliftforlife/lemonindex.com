When problems show up

Half of the Chrysler 300 complaints that listed a mileage came before 42,000 miles. Most came between 17,500 miles and 74,300 miles.

The top problem area, electrical, usually showed up between 28,500 miles and 71,800 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
