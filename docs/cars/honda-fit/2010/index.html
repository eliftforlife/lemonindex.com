When problems show up

Half of the Honda Fit complaints that listed a mileage came before 40,000 miles. Most came between 9,700 miles and 80,200 miles.

The top problem area, airbags, usually showed up between 18,800 miles and 72,200 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
