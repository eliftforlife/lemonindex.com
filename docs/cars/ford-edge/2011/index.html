When problems show up

Half of the Ford Edge complaints that listed a mileage came before 58,000 miles. Most came between 40,000 miles and 86,000 miles.

The top problem area, electrical, usually showed up between 40,000 miles and 77,900 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
