When problems show up

Half of the Volkswagen Passat complaints that listed a mileage came before 32,000 miles. Most came between 7,000 miles and 50,000 miles.

The top problem area, electrical, usually showed up between 23,100 miles and 97,500 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
