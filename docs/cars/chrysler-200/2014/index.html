When problems show up

Half of the Chrysler 200 complaints that listed a mileage came before 55,000 miles. Most came between 17,000 miles and 92,600 miles.

The top problem area, airbags, usually showed up between 30,000 miles and 70,000 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
