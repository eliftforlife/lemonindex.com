When problems show up

Half of the Volkswagen Atlas complaints that listed a mileage came before 14,200 miles. Most came between 2,400 miles and 41,800 miles.

The top problem area, electrical, usually showed up between 8,000 miles and 35,500 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
