When problems show up

Half of the Tesla Model Y complaints that listed a mileage came before 3,800 miles. Most came between 600 miles and 27,100 miles.

The top problem area, automatic emergency braking, usually showed up between 1,000 miles and 10,400 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
