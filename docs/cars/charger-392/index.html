392 HEMI 6.4 engine page →

Why the engine page shows fewer: it counts only the 24 owner complaints and 0 recalls for 2012–2014 that name this engine or a version that only had it. This page counts all 1,351 complaints and 19 recall campaigns NHTSA files under "Charger" for those years, other engines included.

Known issues

  • Lifter and camshaft failure ("HEMI tick")Owner-reported

    Owners report a tick from failed roller lifters that then wear the camshaft. SlashGear links most cases to the cylinder-deactivation (MDS) lifters and low oil flow.

    Fix: Replacing the lifters and camshaft fixes it; on-time oil changes with the right oil help prevent it.

    28 owner complaints to NHTSA mention it (2012–2014)
  • No engine recall on the ChargerRecall

    NHTSA lists no recall for the 6.4 engine on 2012–2023 Chargers. The 2012 SRT8 recall was for the tire-pressure monitor.
