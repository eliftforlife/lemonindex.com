When problems show up

Half of the Chevrolet Sonic complaints that listed a mileage came before 45,000 miles. Most came between 25,000 miles and 69,200 miles.

The top problem area, transmission & drivetrain, usually showed up between 32,000 miles and 75,000 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
