When problems show up

Half of the BMW X1 complaints that listed a mileage came before 69,400 miles. Most came between 30,000 miles and 103,000 miles.

The top problem area, airbags, usually showed up between 19,000 miles and 52,000 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
