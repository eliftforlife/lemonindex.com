When problems show up

Half of the BMW X1 complaints that listed a mileage came before 36,000 miles. Most came between 17,800 miles and 51,500 miles.

The top problem area, transmission & drivetrain, usually showed up between 9,100 miles and 92,000 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
