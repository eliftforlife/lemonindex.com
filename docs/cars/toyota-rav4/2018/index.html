When problems show up

Half of the Toyota RAV4 complaints that listed a mileage came before 12,000 miles. Most came between 4,300 miles and 38,100 miles.

The top problem area, electrical, usually showed up between 6,900 miles and 49,100 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
