When problems show up

Half of the Dodge Dart complaints that listed a mileage came before 49,000 miles. Most came between 31,400 miles and 70,000 miles.

The top problem area, transmission & drivetrain, usually showed up between 40,500 miles and 85,500 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
