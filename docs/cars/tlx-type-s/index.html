Known issues: Acura J30AC

Fuel injection software recall
  • Fuel injection software recallRecall

    On 2021–2025 TLX Type S (and 2022–2025 MDX Type S, 2023–2025 Pilot), a software error in the fuel injection computer may stall the engine or cut power.

    Fix: Dealer reprograms the fuel injection computer (FI-ECU) for free (NHTSA 25V-031).

    5 owner complaints to NHTSA mention it (2021–2025)

Quick answers

How fast is the Acura TLX Type S?

The 2nd-gen TLX Type S makes 355 hp and 354 lb-ft. Car and Driver measured 0–60 mph in 4.9 seconds.

What engine does the Acura TLX Type S have?

The 2nd-gen TLX Type S (2021–2025) uses the Acura J30AC, a 3.0-liter V6, turbo.
