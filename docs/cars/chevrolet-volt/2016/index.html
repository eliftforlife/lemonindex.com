When problems show up

Half of the Chevrolet Volt complaints that listed a mileage came before 43,000 miles. Most came between 29,500 miles and 69,100 miles.

The top problem area, electrical, usually showed up between 22,000 miles and 91,000 miles.

Before you buy one

Run the car's VIN through the free recall check at nhtsa.gov/recalls, and ask for records of any recall work. A complaint is an owner's report, not a confirmed defect, and this is not a repair-cost rating.
