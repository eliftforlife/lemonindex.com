Check engine light / Engine codes

P0325: Knock Sensor 1 Circuit (Bank 1)

P0325 means: Knock Sensor 1 Circuit (Bank 1). You can usually keep driving. Get the code checked when you can. Owners named P0325 in 14 complaints to the U.S. government, most often on the Chevrolet Cruze.

Powertrain · GenericP0325

What P0325 means

The knock sensor signal is missing or out of range, so the computer plays it safe and the engine may feel sluggish.

Can I drive with P0325?

Drive on, get it checked. You can usually keep driving. Get the code checked when you can.

57% of the owner complaints that name P0325 also say the car rattles or knocks. A complaint can describe more than one problem, so this doesn't prove the code caused it.

Common causes of P0325

  • Failed knock sensor
  • Wiring or connector fault

A shop should confirm the cause with a scan and tests before replacing parts.
