P0136: O2 Sensor Circuit (Bank 1 Sensor 2)

Powertrain · GenericP0136
What it means

The downstream O2 sensor (after the catalytic converter) has a fault.

How serious

Drive on, get it checked. You can usually keep driving. Have the code read at your next service or within a few weeks.

Where a shop starts

Failed O2 sensor. Then: wiring fault; exhaust leak.
