BMW

BMW engines ranked by owner complaints, with specs and the cars that have them.

Owners file government complaints by model and year, not engine, so we rank only where the data leaves no doubt: model years where one engine was the only engine in a model we have sales for. By owner complaints per car sold, the M54 ranks best (72) and the N52 worst (149) of the 3 engines we can score that way (100 = average car, lower is better; it counts complaints about the whole car, not just the engine). YouTube tone is shown separately. Each engine page breaks it down by model year.
