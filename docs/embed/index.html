Press · Free embeds

Embed a Lemon Index chart.

Every model we score has a free chart of its owner complaints by model year: 253 models. Paste one line of code into your site, blog or forum post. The numbers update when ours do, and the credit line is built in.

Get the code

<iframe src="https://lemonindex.com/embed/cars/honda-civic/" title="Honda Civic reliability by model year (The Lemon Index)" width="100%" height="813" style="border:0;max-width:720px" loading="lazy"></iframe><p style="font-size:13px;margin:4px 0 0">Data: <a href="https://lemonindex.com/cars/honda-civic/">Lemon Index</a> (Honda Civic reliability by year)</p>

Preview the chart · or use the Embed this chart button under the year chart on any car page.

On a website or blog

  • WordPress: add a Custom HTML block and paste the code.
  • Squarespace: add a Code block. Wix: Embed code → Embed HTML. Ghost: an HTML card.
  • The chart fills the column up to 720 px wide and works on phones. Keep the Data: Lemon Index line under it: that's the credit.
  • Sites that strip iframes (Substack, Medium): post a screenshot of the preview with a link to the car's page instead.

On a forum

  • Most car forums don't allow iframes. Open the preview, take a screenshot, and post it with the car page's link, e.g. Data: Lemon Index, https://lemonindex.com/cars/honda-civic/.
  • Forums that allow HTML embeds (some XenForo and Discourse setups) take the code as is.

In a YouTube video

  • Open the preview full screen, pick Light or Dark to match your edit, and screen-record or screenshot it.
  • Keep the Data: Lemon Index line in frame, or say it, and put the car page's link in your description.

The rules

  • Free for anyone under CC BY 4.0: credit The Lemon Index (lemonindex.com) with a link.
  • Don't change the numbers or cut off the credit line.
  • The chart shows owner complaints per car sold. A complaint is an owner's report, not proof of a defect, and this is not a safety rating. How the index works.
